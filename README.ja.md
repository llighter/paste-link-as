# Paste Link As

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | **日本語** | [Español](README.es.md) | [Français](README.fr.md)

URL を貼り付けて、ノートにどう入れるかを選べます。タイトル付きリンク、インラインのメンション、リンクカードの 3 種類です。すべてプレーンな Markdown で書き込まれるため、プラグインがなくてもノートはそのまま読めます。

![ノート内のメンションとリンクカード](screenshot/sample1.png)

## 使い方

ノートに URL を貼り付けると、すぐに `[タイトル](url)` として入り、その下に小さなメニューが開きます。

- **そのまま**：タイトル付きリンクのままにします。
- **メンション**：ファビコン、サイト名、タイトルを 1 行で表示します。
- **カード**：サムネイル、タイトル、2 行の説明、ファビコンとドメインを表示します。

↑/↓ で選び、Enter（または Tab）で決定、Esc で閉じます。メニューを無視するなら、そのまま入力を続けてください。**そのまま** で Enter を押すと、いつもどおり改行します。

![YouTube の URL を貼り付けると、タイトル付きリンクとして入り、メニューからメンションとカードに変わります](screenshot/sample2.gif)

[MP4 でデモを見る](screenshot/sample2.mp4)

ノートにすでにある URL も変換できます。URL（または `[タイトル](url)` 形式のリンク）を選択して、コマンドを実行します。

- **リンクをカードに変換**
- **リンクをメンションに変換**

何も選択していないときはクリップボードの URL を使い、それもなければ URL を尋ねます。デフォルトのホットキーはないので、Obsidian の設定のホットキーで自由に割り当ててください。

メニュー、コマンド、設定は Obsidian の言語に合わせて表示されます。対応言語は英語、韓国語、中国語（簡体字）、日本語、スペイン語、フランス語です。繁体字中国語は簡体字で、その他の言語は英語で表示されます。

## 書き込まれる内容

**そのまま** はタイトル付きリンクを残します。

```md
[The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
```

メンションは通常の Markdown リンクです。YouTube の動画では、サイト名の位置にチャンネル名が入ります。

```md
[![|16](favicon-youtube.com.png) *チャンネル名* The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
```

カードは `[!link]` コールアウトです。

```md
> [!link] [The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
> ![[link-youtube.com-h5vbt4.jpg]]
>
> The Odyssey - In Theaters 07.17.26…
>
> ![[favicon-youtube.com.png|16]] youtube.com
```

プラグイン専用の記法はありません。プラグインをオフにすると、メンションは通常のリンク、カードは通常のコールアウトとして表示され、見た目だけがなくなります。

カードやメンションは、どこをクリックしてもリンクが開きます。ライブプレビューでカードを編集するときは、カードの下の行からカーソルを移動して入ってください。

## 貼り付けをそのままにする場合

次の場合はメニューが開かず、通常どおり貼り付けられます。

- クリップボードの内容が URL 1 つではないとき、または画像の URL のとき
- リンク先（`](`）の中、引用符・`<`・`[` の直後、コードの中、プロパティの中に貼り付けたとき
- オフラインのとき

テキストを選択した状態で URL を貼り付けると、そのテキストがリンクになります：`[選択したテキスト](url)`。

リスト、引用、表の中では、メニューに **カード** は表示されません。カードは複数行のコールアウトだからです。

## 設定

- **画像フォルダ**：サムネイルとファビコンの保存先です。空欄にすると、Obsidian の設定にある添付ファイルの場所を使います。

## ネットワークの使用

URL を貼り付けたりコマンドを実行したりすると、プラグインはそのページをサイトから直接取得し、タイトル、説明、画像、ファビコンを読み取ります。カードとメンションを作るときは、そのサイトから画像とファビコンをダウンロードして保管庫に保存します。ほかのリモートサービスには接続せず、ノートの内容をどこにも送信せず、テレメトリもありません。

## 保存されるファイル

- ファビコン：`favicon-<ドメイン>.<拡張子>`、ドメインごとに 1 つ。`.ico` など Obsidian で表示できない形式は PNG に変換します。
- サムネイル：`link-<ドメイン>-<ハッシュ>.<拡張子>`

既存のファイルは再利用されるため、同じサイトの別のリンクを貼り付けても、ファビコンを再ダウンロードしません。

## スタイル

`styles.css` が適用されるのは、カード（`[!link]` コールアウト）とメンション（16px の画像と斜体のサイト名を含むリンク）だけです。ほかのリンクや画像はテーマの見た目のままです。見た目を調整したい場合は、CSS スニペットでこれらのセレクタを上書きしてください。

## 制限事項

- メニューが開いている間、↑/↓ はメニュー内を移動します。カーソルを動かすには、先に Esc を押してください。
- 16px 幅の画像と斜体の文字を含むリンクはメンションとして、種類が `link` のコールアウトはカードとして表示されます。
- Auto Link Title のように、貼り付けた URL を書き換えるほかのプラグインも同じ貼り付けイベントを処理します。1 回の貼り付けが二重に処理されないよう、そのプラグインの貼り付け処理をオフにしてください。

## インストール

- **コミュニティプラグイン**：Obsidian のコミュニティプラグインで「Paste Link As」を検索します（公開後）。
- **手動**：最新のリリースから `main.js`、`manifest.json`、`styles.css` をダウンロードして `<保管庫>/.obsidian/plugins/paste-link-as/` に置き、Obsidian を再読み込みしてからプラグインを有効にします。
