# Paste Link As

[English](README.md) | **한국어** | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Français](README.fr.md)

[Obsidian](https://obsidian.md) 노트에 URL을 붙여넣고 들어갈 모양을 고릅니다: 제목 링크, 인라인 멘션, 링크 카드. 모두 평범한 마크다운으로 저장되므로 플러그인이 없어도 노트를 그대로 읽을 수 있습니다.

![노트 안의 멘션과 링크 카드](screenshot/sample1.png)

## 사용 방법

노트에 URL을 붙여넣으면 바로 `[제목](주소)`로 들어가고, 그 아래에 작은 선택지가 열립니다.

- **그대로**: 제목 링크로 둡니다.
- **멘션**: 파비콘, 사이트명, 제목을 한 줄로 보여 주고, 길면 …로 줄입니다.
- **카드**: 썸네일, 제목, 두 줄 설명, 파비콘과 링크 주소를 보여 줍니다.

↑/↓로 고르고 Enter(또는 Tab)로 바꾸며, Esc로 닫습니다. 선택지를 무시하려면 계속 입력하면 됩니다. **그대로**에서 Enter를 누르면 평소처럼 줄이 바뀝니다.

![YouTube URL을 붙여넣으면 제목 링크로 들어가고, 선택지에서 멘션과 카드로 바뀝니다](screenshot/sample2.gif)

[MP4로 데모 보기](screenshot/sample2.mp4)

노트에 이미 있는 URL도 바꿀 수 있습니다. URL(또는 `[제목](주소)` 링크)을 선택하고 명령을 실행하세요.

- **주소를 카드로**
- **주소를 멘션으로**

아무것도 선택하지 않으면 클립보드의 URL을 쓰고, 그것도 없으면 URL을 묻습니다. 기본 단축키는 없으니 Obsidian 설정의 단축키에서 직접 지정하세요.

선택지, 명령, 설정은 Obsidian의 언어를 따릅니다. 영어, 한국어, 중국어(간체), 일본어, 스페인어, 프랑스어를 지원하며, 번체 중국어는 간체로, 그 밖의 언어는 영어로 표시됩니다.

## 저장되는 형식

**그대로**는 제목 링크를 남깁니다.

```md
[The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
```

멘션은 일반 마크다운 링크입니다. YouTube 영상은 사이트명 자리에 채널 이름이 들어갑니다.

```md
[![|16](favicon-youtube.com.png) *채널 이름* The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
```

카드는 `[!link]` 콜아웃입니다.

```md
> [!link] [The Odyssey | Official Trailer](https://www.youtube.com/watch?v=Mzw2ttJD2qQ)
> ![[link-youtube.com-h5vbt4.jpg]]
>
> The Odyssey - In Theaters 07.17.26…
>
> ![[favicon-youtube.com.png|16]] https://www.youtube.com/watch?v=Mzw2ttJD2qQ
```

플러그인 전용 문법은 없습니다. 플러그인을 끄면 멘션은 일반 링크로, 카드는 일반 콜아웃으로 보이고 모양만 빠집니다.

카드나 멘션은 어디를 눌러도 링크가 열립니다. 라이브 프리뷰에서 카드를 고치려면 카드 아래 줄에서 커서를 위로 옮겨 들어가세요.

## 붙여넣기를 그대로 두는 경우

다음 경우에는 선택지가 열리지 않고 평소처럼 붙여넣어집니다.

- 클립보드에 URL 하나가 아닌 내용이 있거나 이미지 URL이 있을 때
- 링크 주소 자리(`](`) 안, 따옴표·`<`·`[` 바로 뒤, 코드 안, 속성 안에 붙여넣을 때
- 오프라인일 때

글을 선택한 채 URL을 붙여넣으면 그 글이 링크 제목이 됩니다: `[선택한 글](주소)`.

목록, 인용, 표 안에서는 선택지에 **카드**가 없습니다. 카드는 여러 줄짜리 콜아웃이기 때문입니다.

## 설정

- **이미지 폴더**: 썸네일과 파비콘을 저장할 위치입니다. 비워 두면 Obsidian 설정의 첨부파일 위치를 씁니다.

## 네트워크 사용

URL을 붙여넣거나 명령을 실행하면, 플러그인은 그 페이지를 해당 사이트에서 직접 요청해 제목, 설명, 이미지, 파비콘을 읽습니다. 카드와 멘션을 만들 때는 그 사이트에서 이미지와 파비콘을 내려받아 볼트에 저장합니다. 다른 원격 서비스에는 접속하지 않고, 노트의 내용을 어디에도 보내지 않으며, 텔레메트리도 없습니다.

## 저장되는 파일

- 파비콘: `favicon-<도메인>.<확장자>`, 도메인마다 하나입니다. `.ico`처럼 Obsidian이 표시하지 못하는 형식은 PNG로 바꿉니다.
- 썸네일: `link-<도메인>-<해시>.<확장자>`

이미 있는 파일은 재사용하므로, 같은 사이트의 다른 링크를 붙여넣어도 파비콘을 다시 내려받지 않습니다.

## 스타일

`styles.css`는 카드(`[!link]` 콜아웃)와 멘션(16px 이미지와 기울임 사이트명이 든 링크)에만 적용됩니다. 다른 링크와 이미지는 테마 모양 그대로입니다. 모양을 바꾸려면 CSS 스니펫에서 이 선택자를 덮어쓰세요.

제목 굵기는 `--paste-link-as-title-weight`(기본 500)를 따릅니다. 바꾸려면 `body { --paste-link-as-title-weight: 600; }` 같은 CSS 스니펫을 추가하세요.

## 제한 사항

- 선택지가 열려 있는 동안 ↑/↓는 선택지 안에서 움직입니다. 커서를 옮기려면 먼저 Esc를 누르세요.
- 라이브 프리뷰에서는 멘션이 든 줄이 커서가 올 때까지 한 줄로 유지되고 끝이 …로 줄어듭니다. 그 줄의 다른 글도 함께 줄어듭니다.
- 16px 폭 이미지와 기울임 글자가 든 링크는 멘션으로, 유형이 `link`인 콜아웃은 카드로 보입니다.
- Auto Link Title처럼 붙여넣은 URL을 바꾸는 다른 플러그인도 같은 붙여넣기 이벤트를 처리합니다. 한 번 붙여넣은 것을 두 번 처리하지 않도록 그 플러그인의 붙여넣기 기능을 끄세요.

## 설치

- **커뮤니티 플러그인**: Obsidian의 커뮤니티 플러그인에서 "Paste Link As"를 검색합니다(등록된 뒤).
- **수동 설치**: 최신 릴리스에서 `main.js`, `manifest.json`, `styles.css`를 내려받아 `<볼트>/.obsidian/plugins/paste-link-as/`에 넣고, Obsidian을 다시 불러온 뒤 플러그인을 켭니다.
